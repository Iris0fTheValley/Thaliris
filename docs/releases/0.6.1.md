# Thaliris Core 0.6.1

Core 0.6.1 adds schema 12 for cross-host managed-child handoff records and
version-3 archive segment collection. It adds the Core-side foreign-runner
lifecycle, claim provenance and usage cost basis fields, and safely collects
unreferenced version-3 segments while preserving segments pinned by recoverable
authority snapshots. Schema 6 through 11 states continue to read forward and
are promoted on write; older Core versions refuse schema 12.

This release adds Core APIs and ledger behavior. Host-specific launch, relay
and foreign-child recognition remain responsibilities of the adapters; see
the [cross-host protocol](../thaliris-cross-host-protocol.md) for that contract.
