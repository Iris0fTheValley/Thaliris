# Thaliris Core 0.6.2

Core 0.6.2 makes authority mode changes and recovery fail closed when the archive-pin
registry cannot be read or updated. Mode changes pin the previous and next ledger
snapshots before publishing the ledger and anchor; if anchor publication fails after
the ledger write, Core restores the exact previous ledger bytes.

Recovery pins the restored ledger for the live anchor and retains a separate pin for
the archived prior anchor and displaced ledger before creating the recovery backup or
restoring project and adapter state. These recovery snapshots remain readable after
later segment collection and authority retirement. A callback failure does not roll
back arbitrary project or native side effects that already occurred; the old anchor
remains available for a same-digest retry, and the per-attempt backup is retained.

The foreign-runner ledger API and schema remain unchanged. The shared protocol allows
the dispatch adapter to select and authorize either the Controller's native session
or an optional native relay as the transport actor.
